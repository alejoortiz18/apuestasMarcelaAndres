Guía ilustrada, pantalla por pantalla, de la aplicación web de administración. Cada vista se reproduce tal como se ve en el sistema y cada botón, campo, filtro, tabla y mensaje está señalado con un número azul que se explica en las tarjetas que aparecen debajo de la imagen.

Las imágenes de este documento son réplicas fieles de las pantallas del administrador. No son interactivas: sirven para reconocer cada elemento antes de usarlo en el sistema real. Los datos que aparecen (nombres, loterías, valores y fechas) son ejemplos.

Cambiar contraseña

Debe cambiar la contraseña temporal antes de continuar.

La nueva contraseña debe tener mínimo 8 caracteres, una mayúscula, una minúscula, un número y un carácter especial (por ejemplo Admin123*).

  1. Motivo del cambio

    Informa que la contraseña actual es temporal y que debe reemplazarse antes de continuar.

    8
  2. Requisitos de la contraseña

    Mínimo 8 caracteres, con al menos una mayúscula, una minúscula, un número y un carácter especial. Ejemplo válido: Admin123*.

    8
  3. Contraseña actual

    Escriba la contraseña temporal con la que acaba de ingresar.

    8
  4. Contraseña nueva

    Escriba la contraseña definitiva que usará de ahora en adelante, cumpliendo los requisitos.

    8

    Repita exactamente la contraseña nueva. Si no coincide, el sistema muestra el error bajo el campo.

    8
  6. Mostrar contraseña

    8

    8
