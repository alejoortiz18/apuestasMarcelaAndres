Manual de usuario del Sitio del vendedor

Guía ilustrada, pantalla por pantalla, de la aplicación web del vendedor web. No es el PDA: este sitio es solo para el rol Vendedor web. Cada control se señala con un número azul explicado en las tarjetas de abajo.

Aplicación: New Rich Sitio del vendedorActualizado noviembre 2026Español de Colombia

Cómo leer este manual

Las imágenes son réplicas de las pantallas del sitio (puerto habitual 5001 en producción web local). Los datos son ejemplos. El vendedor de PDA no entra aquí; el vendedor web no usa PDA ni pertenece a grupos.

Pantalla 1.2

Cambiar contraseña temporal

Si el administrador restableció la clave o es el primer ingreso, el sistema exige una contraseña nueva antes de mostrar el Resumen.

Requisitos. Mínimo 8 caracteres, con mayúscula, minúscula, número y carácter especial. Campos: contraseña actual, nueva y confirmación. Botón Guardar contraseña.
Pantalla 1.3

Sesión vencida

Si pasa el tiempo de inactividad configurado por el administrador, al volver aparece el aviso La sesión venció. Ingresa de nuevo. y debe autenticarse otra vez.

Cerrar sesión e inactividad

Salida voluntaria y cierre automático por minutos sin uso.

Pantalla 13.1

Cerrar sesión

En la barra superior, Cerrar sesión termina la cookie del sitio, avisa al API y vuelve a Iniciar sesión.

Inactividad. El tiempo lo define el administrador en la configuración operativa. Al cumplirse, la sesión expira y al siguiente clic se pide ingresar de nuevo (pantalla 1.3).
